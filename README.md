# KJA IKA SURYA - Company Profile Website

Website company profile untuk **KJA IKA SURYA Semarang**, sebuah Kantor Jasa Akuntansi profesional yang bergerak di bidang akuntansi, perpajakan, dan konsultasi manajemen.

## Tech Stack

- **React** — UI library
- **Vite** — build tool & dev server
- **React Router DOM** — client-side routing
- **Tailwind CSS** — utility-first styling
